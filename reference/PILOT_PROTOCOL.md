# Internal Pilot Protocol Template
CC0 1.0 – Use, adapt, or ignore.

## Purpose
Run a 90–180 day internal pilot that tests whether the Prompt Ascension scoring model produces useful signal inside a real team or research group.

## Minimum Viable Pilot

### 1. Scope
- 5–25 participants
- One shared domain (strategy, research, engineering, training, etc.)
- Clear start and end dates

### 2. Data Collected per Prompt / Session
- Raw prompt or session artifact
- Self-score or peer-score on the four axes (coherence, foresight, leap, militaristic/strategic)
- Optional: variety tag, time spent, downstream outcome link

### 3. Cadence
- Weekly or bi-weekly scoring windows
- Monthly trajectory review
- Final merit + tier calculation at pilot end

### 4. Success Metrics (choose 2–4)
- Rank-order stability of top quartile across months
- Correlation between early foresight scores and later useful outcomes
- Participant retention / voluntary continued use
- Qualitative judgment from domain experts that the ranking “feels right”
- Any measurable improvement in decision quality or research direction

### 5. Exit Criteria
- Publish internal results (even if negative)
- Decide: discard / adapt / scale

### 6. Guardrails
- No high-stakes personnel decisions based solely on pilot scores
- Transparent formula
- Participants can see their own trajectory

## One-Page Launch Checklist
- [ ] Scoring engine running (see reference/scoring_engine.py)
- [ ] Participants briefed on axes and purpose
- [ ] Logging method chosen (spreadsheet, simple DB, or the reference tracker)
- [ ] Start date set
- [ ] Review cadence scheduled
- [ ] Success metrics agreed
